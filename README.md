# sonando

Tarjeta "sonando ahora" de Spotify para el perfil de [FelipeGo18](https://github.com/FelipeGo18), con la misma estética del perfil (Real Hasta La Muerte x Chrome Hearts).

`api/now.py` corre como función de Vercel: consulta qué suena en Spotify y devuelve un SVG dibujado con `lib/art.py`.

Variables de entorno: `SPOTIFY_CLIENT_ID`, `SPOTIFY_CLIENT_SECRET`, `SPOTIFY_REFRESH_TOKEN`.
